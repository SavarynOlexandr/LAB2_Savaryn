# Peak Store

Адаптивний каталог гірського спорядження на Vue 3 та Vite. Сайт підтримує пошук, фільтрацію за категоріями, сортування за ціною, купівлю та оренду товарів.

## Функціональність

- Дані завантажуються з `public/products.json` через `fetch`.
- Пошук і фільтрація товарів у каталогах.
- Сортування за ціною.
- Окремі режими купівлі й оренди.
- Кошик зі зміною кількості та видаленням товарів.
- Кошик зберігається в `localStorage`.
- Форма оформлення замовлення з перевіркою полів.
- Адаптивна верстка для комп’ютерів, планшетів і телефонів.

## Запуск

```sh
npm install
npm run dev
```

Для production-збірки:

```sh
npm run build
npm run preview
```
